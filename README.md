# Pack design du portfolio

Ce pack contient une skill personnalisée et un brief artistique pour refondre le portfolio existant d'Abdouraouf Youssouf.

## Utilisation simple
1. Ouvrir `BRIEF_PORTFOLIO.md` et le transmettre à l'agent de code avec le lien du dépôt du portfolio.
2. Demander à l'agent de lire `.agents/skills/portfolio-editorial-design/SKILL.md` avant de modifier la page.
3. Lui demander de faire l'audit et de proposer un plan de design avant d'écrire le code.
4. Exiger une prévisualisation desktop/mobile, une passe de critique visuelle et l'exécution du build/tests disponibles.

## Installation manuelle de la skill
Copier le dossier `.agents/skills/portfolio-editorial-design/` dans le dépôt de ton site. Les agents qui reconnaissent les Agent Skills dans `.agents/skills` pourront l'utiliser selon leur configuration. Avec un autre environnement, placer le dossier dans le répertoire de skills documenté par cet agent.

Le pack est un brief de conception : il ne modifie pas automatiquement le site déployé.
